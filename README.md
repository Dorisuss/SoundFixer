# SoundFixer 2

● **RU**

Программа для Windows 10/11: держит выбранные микрофон и наушники устройствами по умолчанию,
поднимает громкость **выше 100%**, меняет голос, озвучивает текст в микрофон и играет звуки
(саундборд). Живёт в трее, окно открывается по клику на иконку.

## Возможности

**Устройства и профили**
- Несколько профилей «микрофон + наушники» (дом, гарнитура, стрим…), переключение из трея.
- Автозапуск вместе с Windows (сразу в трей) и применение профиля при старте.
- Слежение за устройствами по событиям Windows (без постоянного опроса): если игра, Discord
  или подключение гарнитуры поменяют устройство по умолчанию, SoundFixer сразу вернёт нужное.
  Подключили гарнитуру позже — профиль применится сам.
- Фиксация громкости микрофона в Windows: Discord/Zoom/Teams больше не «уводят» уровень.

**Микрофон** (нужен виртуальный кабель, см. ниже)
- Громкость до **1000%** (+20 дБ) с лимитером — без хрипа.
- Срез низкого гула, шумодав (тишина, пока молчите), компрессор (ровная громкость).
- Смена голоса: пресеты «Низкий», «Монстр», «Демон», «Высокий», «Бурундук», «Робот»,
  «Инопланетянин», «Рация», «Пещера», «Стадион» и ручные настройки: высота тона,
  робот, хрип, хорус, эхо, реверберация, рация/телефон.
- «Слышать себя» — контроль эффектов в наушниках.
- Выключение микрофона горячей клавишей (по умолчанию `Ctrl+Alt+M`) и **push-to-talk**
  (в т.ч. боковыми кнопками мыши).

**Озвучка и звуки**
- Озвучка текста в микрофон (голоса Windows, включая русские) — собеседники слышат её
  в Discord, играх и т.д. История фраз, повтор двойным кликом, можно пропустить через эффекты.
- Саундборд: mp3/wav/ogg/flac в микрофон, у каждого звука своя горячая клавиша.

**Наушники** (нужен второй виртуальный кабель)
- Громкость всей системы до **500%** с лимитером.
- 5-полосный эквалайзер и пресеты: бас, голос, игры (слышно шаги), кино, музыка…
- Ширина стерео (от моно до «широко»), баланс, кроссфид для наушников, ночной режим.

## Установка

1. Установите [Python 3.10+](https://www.python.org/downloads/) (галочка **Add Python to PATH**).
2. Запустите `run.bat` — при первом запуске он сам установит зависимости.

Или соберите один `SoundFixer.exe`: запустите `build.bat`, готовый файл будет в папке `dist`.

## Виртуальный кабель: как это работает

Windows не умеет усиливать звук выше 100% и не даёт программам менять ваш голос «на лету».
Поэтому звук идёт через бесплатный виртуальный кабель
[VB-Audio Virtual Cable](https://vb-audio.com/Cable/):

```
Микрофон:  ваш микрофон → SoundFixer (эффекты, громкость, озвучка) → CABLE Input
           Discord/игры слушают «CABLE Output» — это и есть ваш новый микрофон
Наушники:  Windows играет в CABLE-A Input → SoundFixer (громкость, эквалайзер) → наушники
```

1. Установите VB-Cable (для наушников нужен второй кабель — например, VB-Cable A/B или
   VoiceMeeter) и перезагрузите ПК.
2. В SoundFixer: вкладка **Устройства** — выберите *настоящие* микрофон и наушники.
3. Вкладка **Настройки** — выберите кабель для микрофона и (по желанию) кабель для наушников.
4. Включите «Обработку микрофона» / «Обработку наушников» на своих вкладках.

SoundFixer сам назначит виртуальные устройства в Windows, пока обработка включена, и вернёт
настоящие, когда вы её выключите или закроете программу.

## Оптимизация

- Без обработки звука звуковой движок (numpy/pedalboard/PortAudio) вообще не загружается.
- Обработка блока 10 мс — десятки микросекунд (фильтры и эффекты на C++).
- Нет таймеров опроса: устройства, горячие клавиши, второй запуск — всё на событиях Windows.
- Окно создаётся только при первом открытии, индикаторы уровня работают, только пока их видно.
- Из Core Audio читаются только нужные свойства устройств (в разы быстрее, чем через `pycaw.GetAllDevices`).

## Файлы

Настройки и лог: `%APPDATA%\SoundFixer\` (кнопка во вкладке «Настройки»).
Настройки первой версии переносятся автоматически, старая запись автозапуска исправляется.

● **EN**

Windows tray app that keeps your chosen microphone/headphones as default devices (profiles,
autostart, event-driven restore), boosts volume **above 100%** (mic up to 1000%, system up to 500%,
with limiter), changes your voice (pitch, robot, reverb, echo, radio…), speaks typed text into your
mic (Windows TTS), plays soundboard clips with hotkeys, and adds a 5-band EQ, stereo width,
crossfeed and night mode for headphones. Voice/boost features route audio through a free
[VB-Audio Virtual Cable](https://vb-audio.com/Cable/). Run `run.bat` or build `SoundFixer.exe`
with `build.bat`.
